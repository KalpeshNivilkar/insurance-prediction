Under the hood

Prediction type: Regression

Built with Linear Regression — a simple, interpretable algorithm well suited to estimating a continuous value like insurance charges.

What is Linear Regression?

A statistical method that models the relationship between input features and a continuous target by fitting the straight line (or hyperplane) that best minimizes prediction error.

Features used

Age, sex, BMI, number of children, smoker status, and region — the same six fields collected on the prediction form.

Target variable

Charges — the individual medical insurance cost billed, in the original dataset's currency units.

Why Linear Regression fits this problem

Charges scale fairly steadily with factors like age, BMI, and smoking status, and the goal is a single continuous number rather than a category — exactly the setup Linear Regression is built for. It is also fast to train and easy to explain, which matters for a portfolio project.
